Chaliye Phase 2 ko **bilkul simple alfaz** mein, bina technical jargon ke, dobara samjhata hoon.

## Phase 2 asal mein kya hai?

Socho aapke paas ek **bara box (CSV file)** hai jisme 7043 customers ka data hai. Phase 2 mein hum sirf do kaam kar rahe hain:

1. **Us box ko kholna** (load karna)
2. **Us box ke andar jhaank kar dekhna** ke sab kuch sahi hai ya kuch garbar hai (validate karna)

Bas itni si baat hai. Hum abhi kuch **theek nahi kar rahe**, sirf **dekh** rahe hain.

---

## Pehla kaam: `load_data.py` — Box kholna

Ye file sirf ek kaam karti hai: **CSV file ko Python mein le aana.**

Socho ye ek chota sa robot hai jo:
1. Aapse poochta hai "kaunsi file kholoon?"
2. Agar aap kuch na bolo, to wo khud-ba-khud wahi file kholta hai jo humne config mein likhi thi (`telco_customer_churn.csv`)
3. File kholne ke baad bolta hai "Maine file khol li, isme itni rows aur columns hain"
4. Phir wo data aapke haath mein de deta hai taake aap aage istemal kar sako

**Itna hi hai.** Koi cleaning, koi fixing — kuch nahi, sirf kholna.

---

## Dusra kaam: `validate.py` — Jhaank kar dekhna

Ye file data ko **5 sawal** poochti hai:

### Sawal 1: "Kya zaroori cheezein mojood hain?"
Jaise — "Kya `Churn` column hai? Kya `customerID` column hai?"

Agar in mein se koi bhi **gayab** ho, to code **turant chillata hai** aur ruk jata hai — "Rukooo! Kuch gayab hai!" Isay humne kaha tha **"loudly fail"** — chup chap aage nahi barhta.

### Sawal 2: "Kya koi customer do dafa to nahi aaya?"
Jaise agar ek hi banda galti se 2 baar list mein aa gaya ho. Jawab mila: **0** — koi repeat nahi.

### Sawal 3: "Kaunse column mein khaali jagah hai?"
Jaise agar kisi customer ka `gender` column khaali ho. Jawab mila: **sab columns mein 0 khaali jagah** (upar se dekhne mein).

### Sawal 4: "Kya `Churn` column mein sirf 'Yes' ya 'No' hai?"
Ho sakta hai kahin galti se "yes" chhota likha ho, ya koi teesri value aa gayi ho. Jawab mila: **sab theek hai, sirf Yes/No hi hain**.

### Sawal 5 (sabse zaroori): "Kya `TotalCharges` mein kuch chhupi hui khaali jagah hai?"
Ye khaas check tha kyunke humein pehle se shak tha. Jawab mila: **11 jagah par ye column "khaali" hai**, lekin wo **sirf space (" ")** hai, poori tarah khaali nahi — isliye Sawal 3 wala normal check usay pakar nahi paya.

---

## Sabse zaroori baat jo samajhni hai

Normal "khaali jagah dhoondo" wala tareeqa (Sawal 3) sirf wahi khaali jagah pakarta hai jo **bilkul khaali (NaN)** ho. Lekin `TotalCharges` mein khaali jagah **ek space ke roop mein chhupi hui thi** (" ") — jo dekhne mein normal lagti hai lekin asal mein ek number nahi hai.

Agar humne ye **khaas check** na likha hota, to hum sochte "sab kuch perfect hai", aur ye 11 kharab values chup-chap aage chali jatin aur baad mein error ya galat result dete.

**Yehi Phase 2 ka asal sabaq hai:** data ko **sirf upar se mat dekho**, gehrai se check karo, kyunke masle kabhi kabhi chhup jate hain.
